# React Router Study

## Notes

### Browser Router Params

| Param  | Description   |
|-------------- | -------------- |
| basename | The base URL for all locations. If your app is served from a sub-directory on your server, you’ll want to set this to the sub-directory. A properly formatted basename should have a leading slash, but no trailing slash.|
| forceRefresh | If true the router will use full page refreshes on page navigation. You may want to use this to imitate the way a traditional server-rendered app would work with full page refreshes between page navigation. |
